# 《丧尸围城》MVP 开发计划

> 版本: v0.4 (三路汇聚布局 + 2.5D 固定视角 + 灰盒先行)
> 目标: 7 周做出可上线测试的 MVP (微信小游戏首发, 抖音/快手跟进)
> 说明: v0.4 布局改版 (四方守城 → 上攻下守三路汇聚) + "主城自动增兵+开火 + 基地三建筑页面 + 高达机甲 + 空军"
>
> **⚠ 开发策略 (v0.4 确认)**: **玩法优先, 美术后置**。W1-W5 全部用**基础几何体灰盒** (立方体/圆柱/球/胶囊) 搭建, 先把 2.5D 三路玩法做出来跑顺; 正式模型在 W6 **整体替换**, 不允许为迁就模型改玩法逻辑。灰盒规范见《03-美术与建模规范》第 5 节, 可替换性约定见《01-游戏设计文档》2.3 节。

## 1. MVP 范围 (做什么 / 不做什么)

### ✅ MVP 包含
- 核心循环: 波次间隙 (主城自动增兵 + 基地建筑升级) → 波次战斗 → 结算
- **1 个大门** (基地围墙正中央) 为**一级防御目标**, 门破 → 10 秒倒计时 → 坍塌 → 怪物涌入攻主城 (可金币重建, 门塌不等于失败)
- **主城** (基地正中央): **失败判定核心** (HP 8000, 可升级), 门坍塌后怪物攻击主城, 主城 HP 归零 → 游戏失败
- **主城自动增兵**: 每 10s 结算, 友军 <20 的路线自动补兵 (3 路线, 全自动, 无需微操)
- **主城自动开火**: 3 个炮位 (对应三路) 自动索敌开火 (炮弹, 溅射, 1.5s/发)
- **基地三建筑页面**: 点主城 (主城/大门/修理工 3 Tab) / 兵营 (量产/兵种/高达/空军 4 Tab) / 实验室 (科技/塔强化/科技树 3 Tab)
- 7 兵种 (火枪/火油/狙击/喷火/机枪/火箭/轨道) + 2 塔 (机枪塔/火箭炮塔), 各 3 级
- **高达机甲**: 白色高达「白刃」(地面双枪) + 红色高达「赤焰」(飞行导弹), AI 自主作战
- **空军**: 战斗机「猎鹰」(扫射, 2 回合返回) + 投弹机「秃鹫」(投弹, 范围), AI 循环作战
- 修理工自动修门 (可部署多个, 速度可升级) + 大门坍塌后金币重建
- 4 怪物 (普通/快速/装甲/自爆) + 1 Boss (尸王, 第 10 波, 随机传送门出现)
- 3 传送门 (顶部左/中/右) + 3 斜线路线汇聚大门 + 30s 行军 + 充能预警
- **2.5D 相机** (3D 场景 + 固定朝向斜俯视角, 仅上下拖拽 / 缩放 / 双击推近 / 回中, **不支持水平旋转**) + 加强保护机制 (方案 B)
- **灰盒先行**: W1-W5 全部单位/建筑用基础几何体灰盒, Prefab 双层结构 (`逻辑节点` + `Visual`), 模型可整体替换
- 科技树 4 分支 × 5 级 (局内)
- 跨局解锁 (兵种/塔/高达/空军按累计波数解锁, 兵营金币解锁)
- 完整 UI: 开始/战斗/主城/兵营/实验室/结算/失败/科技树/设置
- 新手引导 (前 3 波)
- 分享 + 排行榜 (微信平台)
- 3 档画质

### ❌ MVP 不做 (v1.1+)
- 电磁塔、飞行丧尸、看广告复活
- 皮肤系统、PVP/异步对战
- 每日任务/成就系统
- 内购 (MVP 纯免费 + 广告位预留)

## 2. 里程碑 (7 周)

| 周 | 里程碑 | 交付物 | 验收标准 |
|---|---|---|---|
| W1 | 技术验证 + 灰盒规范 | Cocos 工程 + 竖屏 3D 场景 + Toon Shader 占位版 + **2.5D 相机 (上下拖拽/缩放/双击推近/回中, 固定朝向)** + **3 传送门灰盒** (顶部左中右) + **基地灰盒** (底部: 围墙+大门+主城/兵营/实验室+塔位) + **Prefab 双层结构与挂点规范落地** (《03》第 5 节) | 灰盒基地跑 60fps (中端机), 相机操作流畅; 任一单位换 `Visual` 子节点不影响逻辑 |
| W2 | 核心战斗 | **传送门充能/开启 + 3 路线斜线行军汇聚大门 (30s 节奏)** + 怪物 AI/攻击大门 + 友军自动列阵开火 + 子弹/溅射 + 门 HP/破碎/10s 倒计时/坍塌/重建 + 修理工自动修门 + **主城自动开火 (3 炮位)** | 灰盒模型下完整波次可玩, 门破-救援-坍塌-重建-主城-失败链路跑通 |
| W3 | **主城自动增兵** | 主城增兵逻辑 (10s 结算/20 上限/缺兵补兵) + 友军自动走向三路防线 + 兵营量产兵种切换 | 三路线友军自动维持, 缺兵自动补, 无需微操 |
| W4 | 基地建筑页面 + 经济 | 主城/兵营/实验室 3 页面 UI (3+4+3 Tab) + 围墙塔单塔升级 + 实验室塔全局强化 + 金币/兵种解锁升级/修理工/大门/主城/高达/空军升级 | 完整核心循环 (灰盒), 三建筑所有升级可用 |
| W5 | 高达 + 空军 + 科技树 + Boss | 高达 (白刃/赤焰) AI 作战 + 空军 (猎鹰/秃鹫) 循环作战 + 登场演出 + 实验室科技树 UI/逻辑 + 波次成长公式 + Boss | 高达/空军可部署作战, 能打到第 20 波不崩 |
| W6 | 美术替换 | 全部正式模型/特效/UI **按灰盒规范整体替换** (只换 `Visual` 子节点 + Prefab 路径开关) + 新手引导 | 视觉验收 (剪影测试 + 5 米测试), 高达/主城精致度达标; 替换后玩法逻辑 0 修改 |
| W7 | 平台 + 调优 | 微信构建/分享/排行榜 + 性能优化 + 数值调参 | 真机 30fps 保底, 包体 < 30MB |

**风险缓冲**:
- **灰盒先行是本项目降风险的核心手段**: W1-W5 不被美术进度阻塞, 玩法/数值/性能可提前 5 周验证; 若 W6 资产延期, 可先带灰盒上线小范围内测 (灰盒本身可玩)
- W6 美术替换是最大风险 (资产质量/数量, 尤其高达/主城), 建议 W1 就启动资产采购, 与开发并行; 每类资产 (怪物/友军/塔/建筑/传送门) 独立 commit, 可分批替换、随时回退
- 高达是质量重点 + 技术难点 (飞行/导弹/AI), 空军是新增系统 (循环作战), W5 单独一周, 若延期可砍红色高达 + 投弹机 (只留白刃 + 战斗机) 保 MVP

## 3. 工程结构 (Cocos Creator 3.8)

```
assets/
├── Scenes/
│   ├── Boot.scene          # 加载/资源预热
│   ├── Main.scene          # 战斗主场景 (基地 + 三路战场 + HUD)
│   └── UI/                 # 各弹窗 Prefab (含主城/兵营/实验室页面)
├── Scripts/
│   ├── Core/               # GameFlow (波次状态机), Economy, SaveManager, BattleCamera (2.5D: 上下拖拽/缩放/双击推近/回中/轻移, 固定朝向), VisualSlot (灰盒↔正式模型切换)
│   ├── Battle/
│   │   ├── Monster/        # MonsterBase, MonsterAI, MonsterSpawner, BossAI
│   │   ├── Defender/       # DefenderBase (7 兵种), TurretBase (塔), Repairman (修理工), Targeting
│   │   ├── Mecha/          # MechaBase, MechaWhite (白刃), MechaRed (赤焰, 飞行), MechaAI
│   │   ├── Air/            # AirBase, Fighter (猎鹰, 扫射), Bomber (秃鹫, 投弹), AirAI (循环作战)
│   │   ├── Projectile/     # Bullet, Rocket, Beam (轨道/狙击), FireOil, Flame, Missile, Cannonball (主城炮弹), Bomb (投弹机)
│   │   └── City/           # Gate (大门, HP/4 级状态/破碎/重建), GateBreakCountdown (10s 救援), Portal ×3 (传送门 3 级状态), Route ×3 (斜线路线), Wall (围墙+塔位), Tower (单塔独立升级), HQ (主城, 自动增兵+开火+HP), Barracks (兵营), Lab (实验室)
│   ├── HQ/                 # HQReinforcement (自动增兵: 10s 结算/20 上限/3 路线缺兵补兵), HQCannon (3 炮位自动开火), MassProduction (量产兵种)
│   ├── Tech/               # TechTree, TechNode
│   ├── UI/                 # 各面板控制器 (含 HQPanel 主城 / BarracksPanel 兵营 / LabPanel 实验室 / TowerCard 单塔升级)
│   └── Platform/           # WeChat/DouYin/Kuaishou 适配层 (storage/share/ads)
├── Art/
│   ├── Greybox/            # ★ 灰盒 Prefab (W1-W5 使用, Grey_ 前缀, 与 Models 同名结构)
│   │   ├── Monster/  Defender/  Tower/  City/  Portal/  Mecha/  Air/
│   ├── Models/             # 正式模型 (W6 替换): 怪物/兵种/高达/空军/建筑 (含 3 级进化)
│   ├── Animations/         # 动画 Clip (状态机只认动画名, 灰盒用缩放/位移占位)
│   ├── VFX/                # 粒子特效
│   ├── UI/                 # 立绘/图标/面板
│   └── Audio/
├── Prefabs/
│   └── Units/              # 单位 Prefab = 逻辑节点 + Visual 子节点 (双层结构, 见《03》5.1)
├── config/
│   └── models.json         # unitId → { greybox: 路径, formal: 路径 } + useGreybox 开关
└── Shaders/
    ├── ToonShader          # 卡通渲染 (色阶 + 边缘光); 灰盒期用纯色占位版

    └── PortalShader        # 传送门能量漩涡 (3 级状态)
```

### 关键架构决策
1. **波次状态机** (GameFlow): `Prep → Wave → Settle → Prep...`, 所有系统订阅状态变化, 避免全局 if-else
2. **主城自动增兵** (HQReinforcement): 独立 10s 定时器, 每 tick 检查三路线友军数量, <20 则按产能补兵; 与波次状态机解耦 (建设期/战斗期都增兵)
3. **主城自动开火** (HQCannon): 3 炮位独立冷却 (对应三路), 射程内 (16m) 有怪物时自动索敌开火, 优先打最近/威胁最高
4. **目标选择**: 统一 Targeting 组件 (最近/最前/最高威胁 3 种策略), 兵种/塔/高达/空军/主城炮位共用
5. **高达 AI** (MechaAI): 白刃地面追击 (寻路到最近密集敌群), 赤焰飞行巡逻 (三路轮巡 + 优先 Boss/装甲); 与友军 AI 分离 (高达可跨围墙/飞行)
6. **空军 AI** (AirAI): 战斗机 (起飞 → 扫射 2 回合 → 返回整备 3s → 再飞), 投弹机 (起飞 → 投弹 5 枚 → 返回整备 4s → 再飞); 无 HP (MVP 简化), 整备期间无法攻击
7. **对象池**: Monster/Defender/Projectile/Particle 四池, 池大小按"同屏 100 怪 + 60 友军"配置
8. **数据驱动**: 兵种/塔/高达/空军/怪物/波次/科技/建筑升级全部 JSON 配置表, 调参不改代码
9. **平台适配层**: `IPlatform { save/load/share/rank/ads }`, 三平台各一个实现, 开发期用 Mock
10. **2.5D 相机** (BattleCamera): 透视 3D 场景 + **固定朝向** (正对基地, 俯角 55°), 只实现"纵向平移 + 缩放 + 双击推近 + 回中", **不做水平旋转**; 相机目标点用 clamp 限制在场景纵深内, 逻辑比轨道相机简单一半
11. **视觉与逻辑分离** (VisualSlot): 单位 Prefab = `逻辑节点` (脚本/碰撞/挂点/状态机) + `Visual` 子节点 (仅模型); `config/models.json` 的 `useGreybox` 开关决定加载 `Art/Greybox/` 还是 `Art/Models/`。**换模型 = 换 Prefab 路径, 逻辑脚本 0 修改**; 灰盒与正式模型必须同锚点 (脚底中心 Y=0)、同朝向 (-Z 为前)、同尺度 (1 单位 = 1m)

## 4. 性能预算 (真机红线)

| 项 | 预算 | 手段 |
|---|---|---|
| Draw Call | ≤ 120 | 静态合批 (基地/主城/兵营/实验室) + 动态合批 (怪物/友军同材质) + 图集 (UI/粒子) |
| 同屏怪物 | ≤ 100 | 波次公式上限 + 对象池 |
| 同屏友军 | ≤ 60 (3×20) | 主城 20 上限 + 对象池 |
| 粒子 | ≤ 600 | 特效池化 + 低画质减半 (高达/空军特效较多) |
| 内存 | ≤ 512MB | 贴图压缩 (ASTC) + 音频流式加载 |
| 包体 | ≤ 30MB (首包) | 首包只含 W1-W4 资产; 皮肤/额外 BGM 远程下载 |
| 帧率 | 30fps 保底 (骁龙 7 系) | 画质分级 + 怪物/友军 LOD (距离 > 20m 关骨骼动画用贴片) |
| 相机操作 | 拖拽/缩放不掉帧 | 2.5D 固定朝向, 无需重算遮挡与合批; 相机移动时 LOD 更激进 (>15m 即贴片); 传送门 Shader 固定 3 个; 场景纵深 30m 内静态物全部合批 |
| 高达 | 最多 3 台同屏 | 高达始终全精度 (数量少), 飞行用简单物理 (非完整物理引擎) |
| 空军 | 最多 3 架同屏 | 空军始终全精度 (数量少), 飞行用简单路径 (非完整物理引擎) |

## 5. 数值调参流程

1. 所有数值集中在 `config/*.json`
2. 内置"自动模拟"调试面板 (开发者模式): AI 按固定策略自动升级/部署高达/空军, 跑 100 局
3. 输出: 各波次通过率曲线 → 目标: 波 5 = 95%, 波 10 = 70%, 波 20 = 30%, 波 30 = 10%
4. 每次改数值必须重跑模拟, 曲线偏离目标 ±10% 则回炉
5. **主城增兵专项**: 验证"20 上限 + 缺兵补兵"在三路线不同压力下的友军总量曲线, 确保前期不溢出、后期不枯竭
6. **主城 HP 专项**: 验证"门坍塌 → 怪物攻主城"的 DPS 曲线, 确保主城 HP 8000 在门塌后能撑 30-60s (给玩家重建/救援时间)
