# 《丧尸围城》游戏设计文档 (GDD)

> 版本: v0.4 (三路汇聚布局: 基地居底, 三传送门居顶)
> 平台: 微信 / 抖音 / 快手 小游戏
> 引擎: Cocos Creator 3.8.x
> 视角: 竖屏 3D **固定高角度相机** (上下平移 / 缩放 / 双击推近, 默认俯角 55°)
> 题材: **现代军事基地 + 机甲 (高达)** 抵御维度裂隙涌出的丧尸

---

## 1. 游戏概述

### 1.1 一句话描述
玩家是末日基地的**指挥官**, 位于屏幕底部的**主城**自动向三条路线持续增兵并自动开火, 玩家用击杀丧尸赚取的金币, 在**兵营**解锁/升级兵种、在**实验室**升级科技、单独升级围墙防御塔并升级主城与大门, 部署**白色/红色高达**机甲与**战斗机/投弹机**空军, 抵御从顶部三个**传送门**沿三条路线汇聚涌来的丧尸, 守住**大门**与**主城**不被攻破, 挑战无尽波次。

### 1.2 核心体验 (Core Fantasy)
- **运筹帷幄**: 玩家是"大帅", 不直接操控士兵, 而是决定"造什么兵、升什么科技、何时出机甲"。
- **自动增兵的爽感**: 主城源源不断出兵 + 自动开火, 战场始终“有生力量”, 玩家专注布局而非微操。
- **压力与爽感交替**: 波次间隙升级 (爽), 波次来袭守门 (紧张), Boss 波 + 高达登场 (高潮)。

### 1.3 目标用户
- 休闲策略 + 塔防 + 轻放置混合玩法, 15-40 岁
- 单局 5-15 分钟, 竖屏单手操作
- 喜欢军事/机甲题材的玩家

### 1.4 参考作品
| 作品 | 借鉴点 |
|---|---|
| 王国保卫战 | 塔位固定、兵种差异化、科技树 |
| 末日生存/丧尸类 | 题材、传送门、波次压力 |
| 高达/机甲类 | 机甲登场的高潮感、双形态 (地面/飞行) |
| 放置/自动战斗类 | 主城自动增兵的"挂机爽感" |

## 2. 技术选型

### 2.1 结论: Cocos Creator 3.8.x

| 维度 | Cocos Creator 3.8 | Three.js |
|---|---|---|
| 微信/抖音/快手小游戏导出 | ✅ 官方原生支持, 一键构建 | ⚠️ 需自行适配, 生态弱、坑多 |
| 3D 渲染 | ✅ 完整 3D 管线 (PBR/卡通/粒子/后期) | ✅ 强, 但小游戏端需裁剪 |
| UI 系统 | ✅ 成熟 (Widget/动效/九宫格) | ❌ 需自建 |
| 资源管理/对象池/合批 | ✅ 内置 | ⚠️ 需自建 |

**决策: 使用 Cocos Creator 3.8.x。** 三大平台小游戏导出是硬需求, Cocos 是唯一成熟方案。

### 2.2 关键技术点
- **渲染**: 卡通渲染 (Toon Shader) + 柔和阴影, 军事冷色调, 详见《03-美术与建模规范》
- **性能红线** (小游戏端):
  - 同屏怪物 ≤ 100 只, 同屏友军 ≤ 60 (3 路线 × 20)
  - Draw Call ≤ 120
  - 内存 ≤ 512MB
  - 目标帧率 30fps (中低端机保底), 60fps (高端机)
- **对象池**: 怪物、友军、子弹、粒子全部池化
- **静态合批**: 基地建筑 (围墙/防御塔/主城/兵营/实验室) 合批
- **存档**: 三平台 storage API 封装一层, 存最高波数、兵营解锁/主城与实验室升级进度、设置

## 3. 核心玩法

### 3.1 战场布局 (3D 场景, 竖屏呈现)

> **v0.4 布局改版**: 从"四方守城"改为"**上攻下守, 三路汇聚**"。基地在屏幕**最底部**, 屏幕上方 **80% 区域**是敌人的下兵与行军区, 三个传送门在顶部 (左/中/右), 三路兵沿三条斜线**一直出兵围攻底部基地正中央的大门**。

```
 ┌──────────────────────────────────────────┐
 │   [◈ 左传送门]  [◈ 中传送门]  [◈ 右传送门] │ ← 顶部: 3 个传送门 (敌人下兵区)
 │       ╲            │            ╱         │
 │        ╲  左路线   │  中路线   ╱  右路线    │ ← 上方 80% 区域: 三路行军 (30s)
 │         ╲          │         ╱            │
 │          ╲         │        ╱             │
 │           ╲        │       ╱              │
 │            ╲       │      ╱               │
 │             ╲      │     ╱                │
 │              ╲     │    ╱                 │
 │               ╲    │   ╱                  │
 │                ╲   │  ╱                   │
 │                 ╲  │ ╱  ← 三路在门前汇聚   │
 │  ┌───────────────┃━┻━┃─────────────────┐  │
 │  │   [🗼塔位]  ┏━┻━━━┻━┓  [🗼塔位]      │  │ ← 围墙 (弧形/折线) + 沿线塔位
 │  │             ┃  大门 ┃              │  │   大门在正中间 (唯一防御目标)
 │  │  [⚔兵营]    ┗━━━━━━━┛   [🔬实验室]  │  │ ← 基地内部 (底部 20%)
 │  │          [ 🏰 主城 ]               │  │   主城居中, 兵营/实验室分列两侧
 │  └─────────────────────────────────────┘  │
 └──────────────────────────────────────────┘
```

- **基地**: 位于**屏幕最底部** (场景下缘), 由**弧形/折线围墙**围合, 围墙**正中央**是唯一的**钢制防爆大门**; 围墙沿线分布 **4-6 个塔位** (机枪塔/火箭炮塔), 塔口朝外拦截行军中的怪物
- **基地内 3 座建筑** (点击进入对应功能页面, 见 3.8):
  | 建筑 | 位置 | 功能 |
  |---|---|---|
  | 🏰 **主城** | 基地正中央 (大门正后方) | 升级主城 (解锁/提升产能、友军上限、主城火力) + 升级大门 HP; **基地核心, HP 归零 = 游戏失败** |
  | ⚔ **兵营** | 基地左侧 | 解锁新兵种 / 升级兵种 (伤害/攻速/射程) / 设定量产兵种 |
  | 🔬 **实验室** | 基地右侧 | 升级科技 (攻击/速度/防御全局加成, 含防御塔全局强化); 即原"铁匠铺"定位 |
- **3 条路线**: 从左/中/右三个传送门各引出 1 条**斜线路线**, 在底部**汇聚于大门前**——三路敌军最终都打同一个门, 火力分配与路线拦截是核心策略
- **3 个传送门**: 路线起点, 微微发亮的能量光门, 怪物从中涌出; 每波随机开启 1-3 个
- **怪物行军节奏**: 怪物从传送门出现后, **约 30 秒**走到大门前 → 玩家有 30 秒"行军窗口期"观察来敌、调防
- **Boss 波**: Boss 从**随机传送门**出现 (波次预览提前公布方向)
- **胜负**:
  - **大门被攻破** (HP 归零) → 怪物涌入基地屠杀 → 进入 **10 秒倒计时**, 倒计时内修理工未将门修回 1 HP → **大门坍塌**; 但**门塌不等于失败**——怪物涌入后攻击主城, 玩家可用金币**重建大门** (见 3.7)
  - **主城 HP 归零 → 游戏失败** (基地死了才算输); 无尽波次, 记录最高波数

### 3.2 相机与地图操作 (3D 相机, 竖屏)

> 核心体验: 布局是"上敌人下基地"的纵向战场, 相机以**俯瞰全局**为主, 玩家上下平移查看三路来敌, 双击推近看局部战况。

| 手势 | 操作 | 限制 |
|---|---|---|
| 单指拖动 | 平移地图 (相机沿纵向移动) | 上: 不超过传送门外 5m; 下: 不超过基地下缘 |
| 双指旋转 | 绕基地中心小角度旋转视角 | 限制 ±30° (保持"上敌下我"的空间认知) |
| 双指捏合 | 缩放 (俯角 40°-75°) | 最小: 全战场 (3 门 + 基地同屏); 最大: 大门特写 (约 8m) |
| 双击某传送门 | 相机快速推近该门 (0.5s 平滑) | 再双击任意处返回默认 |
| 双击大门 | 相机推近大门 (距离 8m, 俯角 45°) | 显示门 HP 大数字 + 修理工数量 |
| 点击基地建筑 | 进入对应功能页面 (主城/兵营/实验室) | 见 3.8 |
| [⌂ 回中] 按钮 | 相机回到默认位 (全战场俯瞰) | HUD 右下角常驻 |

**默认视角**: 战场纵向中心偏下 (基地占下 1/3, 三路行军区占上 2/3), 俯角 55°, 距离 34m, 正对基地。

**⚠ 加强保护机制 (方案 B)** —— 玩家要关注三路来敌, 不能只盯一路:
1. **路线受击强提示**: 某路线怪物进入射程/大门被攻击时, 该路线指示**红色强闪烁** + 屏幕对应方位边缘**红色脉冲** + 短促警报音
2. **相机轻移**: 大门 HP 跌破 50% 且不在视野内时, 相机**轻微自动平移**朝向该路线 (仅移动不缩放, 0.8s 平滑), 玩家可立即手动覆盖
3. **方位箭头**: 传送门充能预警且该门在视野外时, 屏幕边缘出现闪烁箭头 (◀左上/▲中上/▶右上), 点击自动转向
4. **设计意图**: 提示足够强, 但**不替玩家决策**——玩家仍要主动巡视三路、分配高达与升级, 保持"守三路"的策略张力

### 3.3 主城自动增兵 (本作核心机制)

> 主城是"自动兵工厂 + 自动火力点", 让战场始终有"有生力量", 玩家专注布局而非微操。

**规则**:
1. 主城**每隔 10 秒**结算一次增兵
2. 每条路线维护一个**友军有生力量上限 = 20** (可升级, 见主城升级)
3. 结算时, 对每个**友军数量 < 20** 的路线, 自动增兵 `产能` 个 (基础产能 = 1, 可升级至 2/3)
4. 已 ≥20 的路线**停止增兵**
5. 增兵**全自动, 无需玩家操控**: 新兵从兵营走出 → 自动前往对应路线防线 → 自动列阵 → 自动索敌开火
6. 新兵类型 = 玩家在**兵营**设定的**量产兵种** (默认火枪手)

**示例** (3 路线):
```
左路: 20/20 (满)  → 不增兵
中路: 15/20 (缺) → 增兵 1 (产能1) 或 2 (产能2)
右路: 18/20 (缺) → 增兵 1 或 2
```

**设计意图**:
- "自动增兵" = 轻放置爽感, 战场不会"空了", 玩家掉线感低
- "20 上限 + 缺兵才补" = 资源聚焦在受攻击路线, 天然合理
- 玩家策略 = **选什么兵量产** (组成) + **何时升级产能/上限** + **高达与塔的配置**

### 3.4 核心循环

```
波次间隙 (建设期, 15-30s)
  → 主城自动增兵补齐三路
  → 玩家点基地建筑进功能页面: 主城 (升主城/升大门/重建门) / 兵营 (换量产兵种/升兵种/解锁兵种) / 实验室 (升科技: 攻击·速度·防御·塔强化) / 围墙塔位 (单塔升级)
  → 点击"开始波次" (可提前, 奖励金币)
波次来袭 (战斗期)
  → 传送门充能预警 → 怪物沿 3 路线行军 (30s) 汇聚大门
  → 三路友军自动开火 + 围墙塔自动攻击 + 主城自动开火 + 高达/空军 AI 作战
  → 玩家巡视三路, 紧急调高达/补升级
  → 击杀获得金币
波次结算
  → 波次奖励金币
  → 每 10 波 Boss
```

### 3.5 波次系统

| 波次 | 规则 |
|---|---|
| 1-5 | 教学期: 普通丧尸为主, 数量少, 间隔长 |
| 6-10 | 引入快速丧尸、装甲丧尸; 第 10 波 Boss「尸王」 |
| 11-20 | 引入自爆者; 每 5 波精英波 (数量 ×1.5, 奖励 ×2) |
| 21+ | 全怪物混编, 数量与 HP 持续成长, 每 10 波更强 Boss |

**成长公式** (MVP 初值, 后续调参):
- 怪物数量: `8 + wave × 2` (上限 100)
- 怪物 HP: `base × (1 + wave × 0.18)`
- 怪物速度: 缓慢成长, 上限 +30% (**行军总时长锁定 ≈30s**, 通过传送门距离实现)
- 生成方向: 每波随机 1-3 个**传送门** (左/中/右), 波内分批 (每批 3-8 只, 间隔 1-2s); 传送门开启前 2s "充能预警"
- 路线压力分配: 前期偏重单路 (教学), 中后期三路同时施压; 某路怪物数量可倾斜 (如"右路主攻") 制造防守重心选择
- 提前开战奖励: `剩余秒数 × 2` 金币

### 3.6 经济系统

**金币来源**:
| 来源 | 数值 (MVP 初值) |
|---|---|
| 击杀普通丧尸 | 5 |
| 击杀快速丧尸 | 8 |
| 击杀装甲丧尸 | 15 |
| 击杀自爆者 | 12 |
| 击杀 Boss | 300 |
| 波次结算奖励 | `50 + wave × 10` |
| 精英波奖励 | ×2 |
| 提前开战 | 剩余秒数 × 2 |

**金币消耗** (在基地三座建筑页面 + 塔位进行, 见 3.8):
- **主城**: 升级主城 (产能 / 友军上限 / 主城 HP / 炮位伤害) + 升级大门 HP + **大门重建** (门塌后花金币重建)
- **兵营**: 解锁新兵种 / 升级兵种 (伤害/攻速/射程) / 设定量产兵种 / 解锁与部署高达、空军
- **实验室**: 升级科技 (全局攻击/速度/防御加成, 含防御塔攻防强化) / 升级修理工速度
- **围墙塔位**: 每座塔**单独升级** (点塔直接升级, 塔与塔互不影响); 全局塔强化在实验室

- 金币上限: 9999 (可升级提升)

### 3.7 基地结构

| 部件 | HP (MVP 初值) | 说明 |
|---|---|---|
| **大门** (×1, 正中央) | 1500 (可升级) | **一级防御目标**, 全图唯一可被破坏的防御结构; 被攻击时门顶显示血条; **门塌 ≠ 失败**, 可花金币重建 |
| 围墙 | 无 HP | 纯结构装饰, 不可破坏; 沿线 4-6 个塔位 |
| 防御塔 (×4-6) | 无 HP | 围墙沿线, 朝外攻击行军中的怪物; 每座塔**独立升级** (等级 1-3) |
| **主城** | 8000 (可升级) | **基地核心 = 失败判定**; 位于基地正中央; 自动增兵 + 自动开火 + 空军起飞点; HP 归零 → **游戏失败** |
| 兵营 / 实验室 | 无 HP | 功能建筑 (不可被攻击, 门破后怪物只攻击主城); 点击进入对应页面 |

**大门攻防节奏**:
- 门被啃咬 → 血条下降 → 出现裂纹 (HP<60%) → 冒烟 (HP<30%)
- 门 HP 归零 → 门板破碎 + 全屏红色警报 + **10 秒倒计时**
- 倒计时内修理工把门修回 ≥1 HP → 门"临时加固" (HP 回到 30%)
- 倒计时结束仍未修复 → **大门坍塌** (门洞敞开, 怪物可直接涌入)
- 坍塌后: ① 怪物涌入基地, 攻击**主城**; ② 玩家可随时点门洞 [🔨 重建大门 (金币)] → 3s 建造动画后大门以 **30% HP** 立起 (修理工仍可继续加速); ③ 主城 HP 归零 → **总失败**
- 设计意图: "门掉了没关系, 基地死了才算输"——把"门破即败"的挫败感改成"门破是危机但不是终局", 玩家有第二次机会; 修理工与重建金币是保命核心, 主城是"最后的底线"

### 3.8 基地建筑页面 (点击基地内建筑进入)

> 玩家所有"升级/解锁/部署"操作分散到 3 座建筑, 建筑即菜单, 所见即所得。详见《04-UI界面设计》。

**🏰 主城页面** (点主城建筑进入):
1. **主城升级**: 产能 (1→2→3) / 友军上限 (20→25→30) / 主城 HP / 炮位伤害
2. **大门升级**: 提升大门 HP
3. **大门重建**: 门坍塌后在此 (或点门洞) 花金币重建
4. **修理工**: 部署数量 / 修复速度升级

**⚔ 兵营页面** (点兵营建筑进入):
1. **量产兵种选择**: 选择主城自动增兵的兵种 (默认火枪手, 解锁后可切换)
2. **兵种解锁**: 用金币解锁新兵种 (火油投手/狙击手/喷火兵/机枪手/火箭筒/轨道炮手)
3. **兵种升级**: 每个已解锁兵种可升级 (伤害/攻速/射程), 提升该兵种全体属性
4. **高达部署**: 解锁并部署白色高达 / 红色高达 (见 6)
5. **空军部署**: 解锁并部署战斗机 / 投弹机 (见 6.5)

**🔬 实验室页面** (点实验室建筑进入, 即原"铁匠铺"定位):
1. **科技升级**: 全局 **攻击 / 速度 / 防御** 三线加成 (详见《02-成长树设计》)
2. **防御塔全局强化**: 所有塔的攻击/护甲全局提升 (与"每座塔单独升级"叠加)
3. **科技树**: 4 分支 × 5 级节点 (消耗科技点 TP)

**🗼 围墙防御塔** (直接点场景中的塔):
- 每座塔**只能自己升级自己** (点塔 → [⬆ 升级 (金币)]), 塔与塔之间互不影响, 可分别升到不同等级
- 实验室提供的是**全局百分比加成**, 不替代单塔升级

### 3.9 主城自动开火 (基地火力点)

> 主城不只是"兵工厂", 它本身是**重火力点**, 3 个炮位自动开火, 提供稳定的基础输出。

**规则**:
1. 主城顶部 3 个**炮弹发射点位** (对应左/中/右三路), 朝向上方三条路线
2. 每个炮位**自动索敌**: 射程内 (16m, 可覆盖大半条路线) 有怪物时自动开火, 优先打最近/威胁最高
3. 攻击: 炮弹 (抛物线), 伤害 30, 溅射半径 2m, 攻速 1.5s/发
4. 3 炮位独立冷却, 可同时攻击不同路线的怪物
5. 炮位可升级 (主城页面): 伤害 +30%/级, 溅射 +20%/级, 攻速 +10%/级 (各 3 级)
6. 主城 HP 下降时, 炮位外观战损 (冒烟/火花), 但功能不降 (MVP 简化)

**设计意图**: 主城自动开火 = "免费的基础火力", 让玩家前期不裸防; 3 炮位对应 3 路线, 与围墙塔、三路友军形成纵深交叉火力。

## 4. 兵种设计 (主城量产 + 路线列阵)

> 定位差异: **攻速 × 伤害 × 射程 × 特殊能力** 四轴拉开差距。
> 所有兵种由兵营设定量产、主城持续产出, 自动列阵在三条路线的防线上, 自动索敌开火, 无需微操。

| 3 | 🎯 狙击手 | 高伤单体/反Boss | 很慢 (2.5s) | 极高 (60) | 远 | 对 Boss/装甲丧尸伤害 ×2 | 兵营解锁 |
| 4 | 🔥 喷火兵 | 近距范围 | 持续 (喷射) | 低 (5/s) | 近 | 锥形火焰, 灼烧, 路线防线反群 | 兵营解锁 |

### 4.1 兵种搭配思路 (玩家策略)
- **前期**: 火枪手量产 (便宜、均衡)
- **反群**: 机枪手 + 喷火兵 (路线防线清群)
- **反 Boss**: 狙击手 + 轨道炮手 (高伤穿透)
- **反装甲**: 火箭筒 + 狙击手
- **灼烧流**: 火油投手 + 喷火兵 (持续伤害叠灼烧)
- 玩家可切换量产兵种, 但**已列阵的旧兵种保留**, 形成"混合防线"

## 5. 炮塔设计 (围墙塔位)

> 塔是"固定重火力", 分布在基地**围墙沿线** (4-6 个塔位, 塔口朝外覆盖三条路线), 不可移动, 伤害高于量产兵种。
> **升级规则 (v0.4)**: ① 每座塔**只能自己升级自己**——点塔直接花金币升级, 塔与塔互不影响, 可分别升到不同等级 (策略: 把资源投给压力最大的路线); ② **实验室**提供所有塔的**全局攻击/防御强化** (百分比加成), 与单塔升级叠加。

| 塔 | 定位 | 攻速 | 伤害 | 射程 | 特殊 | 解锁 |
|---|---|---|---|---|---|---|
| 🗼 机枪塔 | 快攻反群 | 很快 (0.2s/发) | 低 (5) | 远 | 持续弹幕, 覆盖一个扇区 | 初始 |
| 🚀 火箭炮塔 | 重击范围 | 慢 (2.5s) | 高 (55) | 中-远 | 火箭弹溅射半径 4m, 可打行军路线 | 兵营解锁 |
| ⚡ 电磁塔 | 减速/控制 | 中 (1.8s) | 中 (12) | 中 | 电磁脉冲减速 40% 持续 2s (v1.1) | 兵营解锁 |

**3 级进化外观**: L1 军用绿 → L2 重装 (加装甲/铆钉) → L3 魔改 (发光能量核心)
**与量产兵种区别**: 塔固定在围墙沿线、覆盖扇区、伤害高; 兵种沿路线防线列阵、数量多、灵活 (可换类型)。

## 6. 高达机甲 (王牌单位, 手动部署 + AI 作战)

> 高达是玩家的"王牌", 用金币解锁后**手动部署**, 部署后 **AI 自主作战**, 是波次高潮的爽点。

| 机甲 | 代号 | 定位 | 攻击 | 特殊 | 解锁 |
|---|---|---|---|---|---|
| 🤖 白色高达 | 「白刃」 | 地面快攻 | 双枪齐射 (两把光束步枪, 0.5s/轮, 每发 20) | 地面高速移动, AI 自动追击最近密集敌群, 可跨越围墙在城内/城外机动 | 兵营解锁 (中后期) |
| 🔴 红色高达 | 「赤焰」 | 飞行重击 | 导弹发射 (肩载导弹舱, 3s/轮, 每轮 3 发 × 40 溅射) | **可飞行** (飞越围墙, 无视地形), AI 自由控制 (自动巡逻三路, 优先打 Boss/装甲), 最高 DPS | 兵营解锁 (后期, 昂贵) |

**高达行为**:
1. 兵营页面解锁 + 部署 (选择出场路线: 左/中/右)
2. 部署后 AI 自主作战: 白色高达地面追击, 红色高达飞行巡逻
3. 高达有 HP, 会被 Boss/自爆者攻击, 损毁后需金币重建 (或看广告复活, v1.1)
4. 同时在场: 白色高达最多 2 台, 红色高达最多 1 台
5. **登场演出**: 白色高达空投 (降落伞 + 落地冲击波), 红色高达从主城机库起飞 (引擎光焰 + 音爆)

**设计意图**: 高达 = "大招", 玩家攒金币解锁/重建, 在 Boss 波或危机时登场, 制造"翻盘爽感"。

### 6.5 空军 (战斗机 / 投弹机, 自动循环作战)

> 空军是"空中火力", 从**主城**起飞, **AI 自主循环作战** (飞出 → 攻击 → 返回 → 再飞出), 无需微操。与高达的区别: 高达是"王牌重单位" (有 HP, 可被击毁), 空军是"循环消耗单位" (无 HP, 自动往返, 持续输出)。

| 机型 | 代号 | 定位 | 攻击 | 作战循环 | 解锁 |
|---|---|---|---|---|---|
| ✈️ 战斗机 | 「猎鹰」 | 空中扫射/反群 | 机炮扫射: 沿飞行路径直线扫射 (每趟 10 发 × 8 伤害, 覆盖一条路线) | 从主城起飞 → **飞越围墙**扫射一条路线 → **扫射 2 个回合** → 返回主城整备 (3s) → 再飞出 (循环) | 兵营解锁 (中期) |
| 💣 投弹机 | 「秃鹫」 | 空中投弹/范围 | 投弹: 沿飞行路径一路投弹 (每趟 5 枚, 每枚溅射半径 3m × 40 伤害) | 从主城起飞 → 沿路线**一路投弹** → 投完返回主城整备 (4s) → 再飞出 (循环) | 兵营解锁 (后期) |

**空军行为**:
1. 兵营页面解锁 + 部署 (选择巡逻路线: 左路/中路/右路, 或"自动轮巡")
2. 部署后 AI 自主循环: 起飞 → 攻击 (扫射/投弹) → 返回主城整备 → 再飞出
3. **战斗机**: 扫射 2 个回合后强制返回 (避免一直滞空), 返回后整备 3s 再飞
4. **投弹机**: 投完 5 枚后返回, 整备 4s 再飞
5. 空军**无 HP** (MVP 简化, 不会被击落), 但整备期间无法攻击
6. 同时在场: 战斗机最多 2 架, 投弹机最多 1 架
7. **登场演出**: 从主城顶部机库起飞 (引擎光焰 + 音爆圈)

**设计意图**: 空军 = "持续空中火力", 与地面兵种/塔/高达形成"空地一体"防线; 战斗机的"2 回合返回"制造节奏感, 投弹机的"一路投弹"提供范围清场。

6. 门破倒计时/坍塌期间: 怪物继续啃咬/攻击主城 (怪物不攻击友军/修理工/高达, MVP 简化; 但 Boss 可攻击高达)

## 12. 数值平衡原则

1. **前 5 波必须能过** (教学期, 主城自动增兵 + 火枪手即可)
2. **第 10 波 Boss 是第一个真实门槛** (需要狙击手/轨道炮 + 1 台白色高达)
3. **第 20 波是普通玩家天花板** (需要完整升级 + 红色高达)
4. **第 30 波+ 是硬核玩家目标**
5. 每次调数值后跑"自动模拟" (AI 自动升级脚本) 验证通过率曲线
