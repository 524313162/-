# 《丧尸围城》UI 界面设计

> 版本: v0.4 (三路汇聚布局: 基地居底, 三传送门居顶)
> 风格: **军事 HUD** —— 深色底 + 夜视绿/琥珀色 + 军用模板字体 (Stencil) + 雷达/瞄准元素
> 设计原则: **单手竖屏操作, 高频操作在屏幕下半区; 信息层级 3 层以内; 反馈即时 (任何点击 0.1s 内有视觉/音效反馈)**

---

## 1. 视觉规范

### 1.1 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 主背景 (UI 底) | #1A1F1A 深军绿黑 | 军事 HUD 底 |
| 面板底 | #2A322A 深绿灰 | 半透明面板 (85% 不透明) |
| 主强调 | #FFB000 琥珀色 | 按钮/高亮/金币/警告 |
| 夜视绿 | #33FF66 | 数据/HP/科技点 (HUD 读数) |
| 危险 | #FF3B30 警报红 | 敌人/门危急/倒计时 |
| 友军 | #4A90D9 钢蓝 | 我方/友军信息 |
| 高达 | #FFFFFF 白 / #FF4444 红 | 王牌单位标识 |
| 主城 | #FFB000 琥珀 | 主城 HP 条 (基地核心, 归零即失败) |
| 文字主 | #E8E8E0 米白 | 主文字 |
| 文字辅 | #8A9A8A 灰绿 | 次要信息 |

### 1.2 字体
- 中文: 思源黑体 (正文) + 军用模板风格 (标题, 可用"站酷高端黑"等免费商用)
- 数字: 等宽粗体 (HUD 读数, 金币/波次跳动时不抖动), 夜视绿
- 最小字号 24px (750 设计稿), 保证小屏可读

### 1.3 组件规范

| 组件 | 样式 |
|---|---|
| 按钮 | 深色底 + 琥珀色边框 + 切角 (军事风, 非圆角); 按下时变亮 + 下沉 2px; 禁用时灰化 50% |
| 卡片 (兵种/塔/高达) | 深色底 + 单位立绘 (3D 渲染 2D 立绘) + 名称 + 价格 (金币图标 + 数字) + 切角边框 |
| 血条 | 大门: 门顶细长条 + HUD 顶部 1 条; 主城: 主城顶长条 + HUD 顶部 1 条 (琥珀色); 怪物: 头顶小圆条 (仅受伤后显示 3s); 高达: 头顶长条 (白/红) |
| 图标 | 2D 军事风 (非 emoji), 64×64, 夜视绿/琥珀描边 |
| 弹窗 | 深色面板 + 琥珀色边框 + 切角 + 顶部"军事模板"标题条 |
| 雷达元素 | 主城/实验室页面/科技树背景用淡雷达扫描线 (装饰, 增强军事感) |

### 1.4 动效规范
- 所有 UI 出现/消失: 0.2-0.3s, ease-out
- 金币变化: 数字滚动 (0.3s) + 琥珀色闪烁
- 波次数字: 放大 1.3 倍弹回
- 按钮点击: 缩放 0.95 + 音效
- 高达相关: 登场时全屏轻微闪光 + 引擎音效
- **禁止**: 超过 0.5s 的动效 (战斗中 UI 必须快)

## 2. 界面清单与布局

### 2.1 主战斗界面 (核心)

```
┌──────────────────────────────┐
│ [⏸]  第 12 波  ◆3  🪙1250   │ ← 顶部 HUD (高 80px)
│ [◈左▓▓░][◈中▓▓▓][◈右▓░░]     │ ← 3 路敌情条 (高 32px, 该路存活怪数)
│ [🚪 大门 ▓▓▓▓▓▓░░░ 68%]       │ ← 大门 HP 条 (钢蓝色, 高 28px)
│ [🏰 主城 ▓▓▓▓▓▓▓▓░░ 82%]      │ ← 主城 HP 条 (琥珀色, 高 28px)
│      [⚔ 下一波: 🧟×14 🏃×6] │   波次预览条
│                              │
│   (3D 场景: 上方三路行军区)    │
│                              │
│   (下方基地: 围墙+大门+三建筑) │
│                    [⌂ 回中]  │ ← 相机回中按钮 (右下, 60×60)
│ ┌──────────────────────────┐ │
│ │[🏰主城][⚔兵营][🔬实验室]  │ │ ← 底部快捷栏 (高 140px)
│ │ [🤖高达] [⚔开始波次(12s)] │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

**顶部 HUD**:
- 左: 暂停按钮
- 中: 波次 (大字, 夜视绿) + 下一波怪物预览 (头像 × 数量, 最多 3 种; Boss 波额外显示"⚠ Boss 从 [中] 路来")
- 右: 科技点 (◆, 夜视绿) + 金币 (🪙, 琥珀色, 带滚动动画)
- **3 路敌情条**: 顶部一排 3 个细条, 按左/中/右排列, 显示该路**存活怪物数量** (颜色与传送门方位色一致: 左红/中紫/右绿); 该路怪物超阈值时**红色强闪烁** + 屏幕对应边缘红色脉冲
- **大门 HP 条**: 敌情条下方 1 条钢蓝色血条, 显示大门 HP 百分比; 仅 HP<100% 时显示, 危急 (<30%) 时**红色强闪烁** + 门顶红色警示灯; 门坍塌后显示 [🔨 重建 (金币)] 按钮
- **主城 HP 条**: 大门 HP 条下方 1 条琥珀色血条, 显示主城 HP 百分比; 危急时**红色强闪烁** + 主城顶红色警示灯 (主城归零 = 失败)

**底部快捷栏** (高频操作, 对应基地三建筑):
- [🏰 主城]: 进入主城页面 (升主城/升大门/重建门/修理工)
- [⚔ 兵营]: 进入兵营页面 (量产/兵种/高达/空军)
- [🔬 实验室]: 进入实验室页面 (科技升级/塔全局强化/科技树)
- [🤖 高达]: 快速部署/查看高达 (已解锁时)
- [⚔ 开始波次 (12s)]: 建设期显示倒计时, 点击提前开战 → 金币 +N 飘字; 战斗期变为 [第 12 波 进行中... 🧟剩余 8]

**相机操作提示** (首次进入战斗时浮层, 3s 后消失):
```
  单指拖动 → 上下查看三路来敌
  双指旋转 → 小角度调整视角
  双指捏合 → 缩放
  双击大门 → 推近查看
  点击基地建筑 → 主城/兵营/实验室
```

**路线引导箭头** (传送门预警 + 门危急):
- 当某传送门充能预警, 且该门**不在当前视野内**时, 屏幕对应边缘出现闪烁箭头 (◀左上/▲中上/▶右上, 方位色)
- 大门 HP<50% 且不在视野内: 箭头变红色强闪烁 + 相机轻微自动平移
- 点击箭头 → 相机自动平滑转向该传送门/大门 (0.5s)
- 设计意图: 玩家不必手动找方向, 一眼知道"哪路来敌了/大门是否危急"

**场景内交互**:
- 点击主城 → 进入**主城页面**; 点击兵营 → **兵营页面**; 点击实验室 → **实验室页面** (建筑高亮 + 光圈)
- 双击大门 → 相机推近大门 (距离 8m, 俯角 45°) + 显示门 HP 大数字 + 正在修复的修理工数量; 再双击任意处返回
- 双击某传送门 → 相机推近该门 (距离 10m, 俯角 45°) 查看该路敌情; 再双击任意处返回
- 点击围墙上的塔 → 弹出该塔小卡片: Lv + 属性 + [⬆ 升级 (金币)] (**每座塔单独升级**, 与实验室全局强化叠加)
- 单指拖动 → 平移地图; 双指旋转 → 小角度旋转; 双指捏合 → 缩放 (详见《01-游戏设计文档》3.2 节)
- [⌂ 回中] 按钮 → 相机回到默认位 (全战场俯瞰, 俯角 55°)
- 点击高达 → 显示高达 HP + [🔧 重建 (金币)] 按钮 (损毁时)
- 点击空军 → 显示空军状态 (整备中/飞行中) + [🔧 重建 (金币)] 按钮 (损毁时, v1.1)

**门破倒计时 UI** (本作最高优先级界面, 必须"心跳感"):
```
┌──────────────────────────────┐
│                              │
│      ⚠ 大门被攻破! ⚠         │ ← 屏幕中央大字 (红色, 抖动)
│         10 秒后门坍塌        │
│         [ 9 ]                │ ← 超大倒计时数字 (每秒缩放脉冲)
│      🔧 修理工修复中 320/1500 │ ← 当前修复进度条
│                              │
│   (全屏红色边缘脉冲 + 警报音效)│
└──────────────────────────────┘
```
- 倒计时数字: 每秒放大 1.2 倍弹回 + 滴答音效 (最后 3 秒变急促)
- 修复进度条: 琥珀色, 实时回升; 修回 ≥1 HP → 倒计时取消 + "门已加固!" 绿色大字 + 门回到 30% HP
- 倒计时结束 → **大门坍塌** (门洞敞开, 怪物涌入攻击**主城**) → 主城 HP 条红色强闪烁 + "⚠ 主城告急!" 警告
- **坍塌不等于失败**: 坍塌后 HUD 大门位置出现 [🔨 重建大门 (金币)] 按钮, 点击后 3s 建造动画, 大门以 30% HP 重建; 修理工也可持续抢修加速
- **主城 HP 归零 → 失败界面** (基地死了才算输)

**防御塔升级** (不在任何页面, **直接点场景中的塔**):
- 每座塔只能自己升级自己 (Lv.1→2→3, 金币递增), 塔与塔互不影响
- 塔卡片: 名称 + Lv + 属性 + [⬆ 升级 (金币)]; 实验室的"塔强化"提供全局百分比加成

**交互**:
- 每个单位卡片: 立绘 + 名称 + 等级 + 属性 + [升级]/[解锁]/[设为量产]/[部署] 按钮
- 金币不足: 按钮灰化 + 价格变红
- 未解锁: 显示锁 + "第 X 波解锁" (跨局解锁条件)
- 升级时: 卡片闪光 + 音效 + 属性数字滚动
- 高达部署: 选择出场路线 (左/中/右 3 选 1) → 高达登场演出
- 空军部署: 选择巡逻路线 (左路/中路/右路/自动轮巡) → 空军从主城机库起飞

## 3. 新手引导 (前 3 波)

| 步骤 | 触发 | 引导内容 |
|---|---|---|
| 1 | 进入战斗 | 手指动画从顶部三传送门划向底部大门: "丧尸从三路来了, 守住底部大门!" |
| 2 | 进入兵营 | 高亮"量产"Tab: "选择火枪手量产" |
| 3 | 返回战斗 | 高亮 [开始波次] 按钮: "开始第一波!" |
| 4 | 波次 1 结束 | 兵营"兵种"Tab 高亮: "用金币升级火枪手" |
| 5 | 波次 2 结束 | 指向围墙塔位: "点击防御塔, 单独升级它" |
| 6 | 波次 3 结束 | 引导相机操作: "上下拖动查看三路来敌" → 引导结束 |

- 引导期间其他操作被软锁定 (可点但提示"先完成这一步")
- 玩家可随时点"跳过引导"

## 4. 平台适配

| 项 | 方案 |
|---|---|
| 设计稿 | 750×1334 (iPhone 8 基准), 竖屏锁定 |
| 安全区 | 顶部留 88px (刘海/状态栏), 底部留 68px (Home 条) |
| 微信 | 右上角胶囊按钮避让 (HUD 右移) |
