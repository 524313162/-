# 《丧尸围城》美术与建模规范

> 版本: v0.4 (三路汇聚布局: 基地居底, 三传送门居顶)
> **核心原则: 拒绝方块堆砌。所有模型必须有"手工雕刻感"——圆润的轮廓、合理的比例、细节纹理、卡通渲染。军事装备要有"真实感 + 卡通化"的平衡, 高达要有"精致机甲感"。**

---

## 1. 整体美术风格

### 1.1 风格定位
**"卡通渲染 + 末日军事 + 机甲"** (Stylized Toon + Modern Military + Mecha)

- 参考: 《王国保卫战》的精致卡通 + 现代军事装备的真实比例 + 《高达》的机甲精致感
- **不是**写实风 (小游戏端性能不允许), **不是**低多边形方块风 (用户明确拒绝)
- 关键词: 圆润、有细节、军事冷色调、轮廓清晰、机甲精致

### 1.2 色彩规范

| 区域 | 色调 | 说明 |
|---|---|---|
| 天空/远景 | 灰蓝 + 橙红晚霞 | 末日黄昏, 压抑但有层次 |
| 地面 | 暗灰 + 土黄 | 荒废混凝土 + 泥地 + 弹坑 |
| 基地 | 军绿 + 混凝土灰 + 钢色 | 军事冷色调, 突出"最后的防线" |
| 主城 | 深灰 + 琥珀色灯光 + 钢色炮位 | 基地核心指挥所, 顶部 3 炮位, 雷达/天线, 夜间亮灯 |
| 兵营/实验室 | 军绿 / 冷蓝灰 | 基地两侧功能建筑, 顶部各 1 标识 (交叉刀/原子环), 夜间亮灯 |
| 怪物 | 病态绿 + 暗红 | 一眼可辨的"敌人色" |
| 友军 | 军绿 + 钢蓝 + 琥珀 | 一眼可辨的"友军色" |
| 高达 | 白色 (白刃) / 红白 (赤焰) | 高对比, 王牌单位的"主角光" |
| UI | 深黑 + 夜视绿/琥珀 | 军事 HUD 风格 |

**色彩纪律**: 敌人 = 绿/红, 友军 = 军绿/钢蓝, 建筑 = 灰/军绿, 高达 = 白/红 (主角), 特效 = 高饱和点缀。任何时刻玩家扫一眼就能分清敌我。

### 1.3 渲染管线 (Cocos 3.8)

| 项 | 方案 |
|---|---|
| 着色器 | 自定义 Toon Shader: 2-3 阶色阶 (Cel Shading) + 边缘光 (Rim Light); 高达用 PBR 金属质感 (金属 + 自发光核心) |
| 阴影 | 烘焙 AO (贴图) + 实时软阴影 (仅塔楼/主城/高达投射, 怪物/友军用假阴影贴片) |
| 怪物/友军阴影 | **圆形渐变贴片** (跟随单位, 零成本, 卡通风完全够用) |
| 后处理 | 轻微 Bloom (爆炸/高达能量/传送门) + 暗角 (Vignette, 增强末日感) |
| 雾效 | 指数雾, 远处怪物/传送门淡入, 隐藏生成点 |
| 画质分级 | 高: 实时阴影 + Bloom; 中: 关 Bloom; 低: 全关 + 降分辨率 |

## 2. 建模规范 (重点)

### 2.1 通用规则

| 规则 | 说明 |
|---|---|
| **禁止纯方块/圆柱堆砌** | 所有模型必须经过"圆润化"处理: 倒角 (Bevel)、球化 (Spherize)、有机变形 |
| 轮廓优先 (Silhouette First) | 剪影必须能一眼认出是什么 (火枪手有枪、火箭筒有筒、高达有机甲轮廓) |
| 夸张比例 | 头身比 1:3 (偏写实), 武器/特征放大 1.3 倍, 增强可读性 |
| 面数预算 | 怪物 ≤ 3000 三角面, 友军 ≤ 3500, 塔 ≤ 6000, 高达 ≤ 12000, 主城 ≤ 18000, 兵营/实验室 ≤ 8000, 飞机 ≤ 5000 |
| 贴图 | 单张 1024×1024 (高达/主城 2048), 含 Albedo + 烘焙 AO; 高达额外用金属度/自发光贴图 |
| 骨骼 | 怪物 20-30 根, 友军 30-40 根, 高达 40-60 根 (含关节/武器挂点) |
| 命名 | `M_Zombie_Normal_Body`, `M_Unit_Gunner_L3`, `M_Mecha_White`, `T_` 贴图前缀 |

### 2.2 怪物建模 (核心资产, 质量最高优先级)

> 怪物是屏幕上的主角, 必须"有血有肉"。

**普通丧尸**:
- 驼背、歪头、一臂前伸 (经典丧尸姿态), 衣服破烂 (用贴图 + 少量几何破口表现)
- 皮肤: 病绿 + 暗斑 (贴图), 边缘光用暗红色
- 动画: 蹒跚行走 (左右摇摆 + 拖步)、攻击 (扑咬, 带顿帧)、死亡 (倒地 + 溶解粒子)
- **细节要求**: 手指 (3 根即可)、破鞋、腰间破布条——这些"小东西"是精致感的来源

**快速丧尸**:
- 瘦削、四肢细长、奔跑姿态前倾, 衣服更少
- 颜色偏暗红, 移动时带残影特效 (2 帧拖影贴片)

**装甲丧尸**:
- 体型 ×1.4, 穿破碎的军用装甲/防弹衣 (几何细节: 装甲板 + 铆钉 + 弹痕)
- 头部比例缩小, 肩部加宽 → 剪影是"倒三角"
- 减伤表现: 被普通攻击时弹火花, 被火箭筒/狙击/轨道炮命中时装甲碎裂
- 死亡时地面震动 (相机微抖)

**自爆者**:
- 圆滚滚的肚子 (明显鼓胀), 身上绑着 C4 炸药包 (几何细节), 肚子有发光裂纹 (自发光贴图, 爆炸前 1s 闪烁)
- 剪影: "圆球 + 小头", 一眼识别危险

**尸王 (Boss)**:
- 体型 ×2.5, 披破烂军大衣, 头戴扭曲钢盔 (几何细节)
- 双持军刀/霰弹枪, 肩部有骨刺 + 装甲残片装饰
- 专属出场: 屏幕震动 + 黑雾粒子 + 专属 BGM 切入
- 面数预算放宽到 8000

### 2.3 友军兵种建模 (兵营设定 + 主城量产)

> 友军站在三条路线的防线列阵, 只露出腰部以上 (围墙遮挡下半身) → **省一半面数**, 且构图更聚焦。

| 兵种 | 剪影特征 | 细节要求 |
|---|---|---|
| 火枪手 | 步枪 + 头盔 | 军绿制服 + 战术背心, 开火时枪口火光 + 烟雾, 头盔有迷彩 |
| 火油投手 | 投掷姿势 + 腰间油瓶带 | 皮手套 + 护目镜, 投掷动画: 后摆 → 抛出 (油瓶抛物线 + 落地爆燃) |
| 狙击手 | 长狙击枪 + 瞄准镜 (占身体 1/2) | 蹲姿/站姿, 开镜动画 (瞄准镜放大特效), 命中时"叮"穿透音效 |
| 喷火兵 | 肩扛喷火器 + 燃料罐 | 全脸防护面罩, 喷射锥形火焰 (橙→黄渐变 + 黑烟), 燃料罐随喷射晃动 |
| 机枪手 | 架式机枪 + 弹链箱 | 蹲姿据枪, 持续弹幕 (曳光弹拖尾), 弹链流动动画, 枪管发红 (持续射击后) |
| 火箭筒 | 肩扛火箭筒 (占身体 2/3) | 后坐力 (筒身后缩), 火箭弹抛物线 + 落地爆炸, 发射时闭眼/护目镜闪光 |
| 轨道炮手 | 背负轨道炮发射器 (大型) | 充能动画 (炮口蓝光汇聚) → 发射 (直线光束穿透), 充能时周围电弧 |

**通用**: 军绿/钢蓝配色, 头盔 + 战术背心 + 弹药带细节; 满级兵种外观强化 (加护甲/发光核心/披风)。

### 2.4 高达机甲建模 (王牌单位, 质量天花板)

> 高达是"主角", 必须精致, 是玩家追求的目标。面数预算 12000, 用 PBR 金属质感。

**白色高达「白刃」** (地面快攻):
- 经典白色机甲 + 蓝色/红色点缀 (头部 V 字天线 + 双眼发光)
- 双持光束步枪 (两把, 枪口蓝色能量), 肩部有小型推进器 (地面高速移动时喷焰)
- 关节: 明显的机甲分段 (肩/肘/膝/踝), 关节处有液压杆细节
- 胸口: 发光能量核心 (蓝色, 呼吸灯效果)
- 动画: 高速奔跑 (地面冲刺 + 残影)、双枪齐射 (两枪交替, 光束弹道)、受击 (火花 + 核心闪烁)、登场 (空投降落伞 + 落地冲击波)
- 剪影: 修长人形 + 双枪, 一眼"白色机甲"

**红色高达「赤焰」** (飞行重击):
- 红白配色 + 金色点缀, 体型比白刃大 20%
- 肩载导弹舱 (两侧各 3 联装, 共 6 发), 背部大型飞行推进器 (飞行时喷蓝色光焰)
- 头部: 更尖锐的 V 字天线 + 红色双眼 (比白刃更"凶")
- 胸口: 红色能量核心 (比白刃更亮)
- 动画: 飞行 (悬停 + 推进器光焰 + 音爆圈)、导弹齐射 (3 发扇形 + 追踪弹道)、受击、登场 (从主城机库起飞 + 引擎轰鸣)
- 剪影: 壮硕人形 + 肩导弹舱 + 背推进器, 一眼"红色飞行机甲"

**高达通用**:
- 金属质感 (PBR: 金属度 0.8 + 粗糙度 0.3) + 自发光核心
- 边缘光 (Rim Light) 用白色/红色, 突出"主角光"
- 地面假阴影 (飞行时阴影缩小/偏移, 体现高度)
- 损毁状态: 冒烟 + 核心熄灭 + 单臂垂落

### 2.5 建筑建模

**基地围墙** (核心视觉, 必须精致):
- 不是直板墙! 基地围墙为底部弧形/折线墙, 塔口朝外。要求: 混凝土预制块 + 钢制加固肋 + 顶部射击孔 (有倒角)、墙面有弹痕/烟熏贴图 + 局部破损几何 (3-4 处凹坑)、墙顶有走道 + 沙袋
- 围墙沿线 4-6 个塔位, 段间有立柱 (带探照灯, 夜间扫光)
- 城墙无 HP (纯装饰), 但保留 2 级"战损贴图" (完好 → 弹痕/烟熏), 随波次推进切换

**大门** (×1, 围墙正中央, 核心交互目标, 质量最高优先级之一):
- 厚重**钢制防爆门** + 液压门框 + 铆钉 + 门顶混凝土拱 (拱顶有军事徽标), 两侧各 1 座小型岗楼 (带探照灯 + 机枪位)
- 门是**唯一可破坏目标**, 必须有清晰的 4 级状态:
  - 完好: 钢制原色 + 军绿涂装
  - 受损 (HP<60%): 弹痕 + 局部凹陷 (几何替换 2-3 块) + 火花
  - 危急 (HP<30%): 冒烟 + 门板大面积破损 + 液压杆扭曲 + 红色警示灯闪烁
  - 破碎 (HP=0): 门板崩碎 (8-12 块碎片物理抛射) + 门洞黑洞 + 红色警报光
- 修复中: 修理工焊接/敲击 + 火花粒子 + 叮当音效 + 门顶血条回升
- 大门两侧各 1 座小型岗楼; 门坍塌后门洞敞开 (可点 [🔨 重建] 按钮, 3s 建造动画后以 30% HP 立起)

**主城** (基地核心, 质量天花板之一):
- **指挥所**主体建筑, 位于基地正中央 (大门正后方), 3 层结构: 底层混凝土基座 (带 3 个卷帘门, 对应 3 路线增兵出口) → 中层指挥塔身 (窗户亮琥珀色灯光 + 天线) → 顶层雷达 (缓慢旋转) + 通信天线 + 机库 (空军起飞点)
- **3 个炮弹发射点位**: 顶部 3 座炮位 (钢制炮塔 + 炮管, 可旋转瞄准), 炮位有独立开火动画 (后坐力 + 炮口火光 + 烟雾)
- 顶部: 旋转雷达 (带扫描光) + 3 面路线灯 (指向左/中/右传送门) + "主城"标识 + 机库 (战斗机/投弹机起飞)
- 增兵动画: 底层 3 个卷帘门开启 → 友军鱼贯而出 → 走向对应路线 (体现"自动增兵")
- 点击热区: 主城/兵营/实验室 3 建筑各自可点击 → 进入对应页面 (点击时建筑高亮 + 光圈)
- **血量很厚 (8000)**, 是**失败判定核心**, 必须有清晰的 4 级战损状态:
  - 完好: 深灰 + 琥珀灯光 + 钢色炮位, 外观完整
  - 受损 (HP<60%): 墙面弹痕 + 局部凹陷 + 1-2 个炮位冒烟
  - 危急 (HP<30%): 大面积破损 + 冒烟 + 火花 + 红色警示灯闪烁 + 3 个以上炮位战损
  - 破碎 (HP=0): 主城坍塌 (碎片物理抛射) + 黑烟 + 红色警报光 → 游戏失败
- 设计意图: 主城是"最后的底线" (基地死了才算输), 血量厚但可被攻破; 门塌不等于失败, 主城才是终局判定

**空军建模** (战斗机 / 投弹机, 从主城起飞):

**战斗机「猎鹰」** (空中扫射):
- 单发战斗机, 军绿 + 钢蓝配色, 机翼有迷彩 + 军事徽标
- 机头有机炮 (2 门, 扫射时曳光弹拖尾), 机翼下有 2 枚导弹 (装饰)
- 动画: 起飞 (引擎光焰 + 音爆圈)、飞行 (悬停 + 推进器光焰)、扫射 (机炮连射 + 曳光弹)、返回 (减速 + 降落)
- 剪影: 单发战斗机 + 机翼, 一眼"战斗机"
- 面数 ≤ 5000

**投弹机「秃鹫」** (空中投弹):
- 双发投弹机, 体型比战斗机大 30%, 军绿 + 土黄配色
- 机腹有弹舱 (投弹时弹舱门打开 + 炸弹下落), 机翼下有 4 枚炸弹 (装饰)
- 动画: 起飞、飞行、投弹 (弹舱门开 + 炸弹抛物线 + 落地爆炸)、返回
- 剪影: 双发投弹机 + 机腹弹舱, 一眼"投弹机"
- 面数 ≤ 5000

**空军通用**:
- 飞行时地面假阴影 (缩小 + 偏移, 体现高度)
- 引擎光焰 (起飞/飞行时, 蓝色/橙色)
- 音爆圈 (起飞/高速飞行时, 白色圆环扩散)
- 整备状态: 停在主城机库 (引擎熄灭 + 灯光)

**围墙防御塔**:
- 3 级进化外观:
  - L1 军用绿: 混凝土基座 + 钢制炮塔 + 迷彩
  - L2 重装: 加装甲板 + 铆钉 + 双联装
  - L3 魔改: 深色金属 + 发光能量核心 + 顶部悬浮能量环
- 炮管/机枪可旋转 (瞄准动画), 开火时后坐力 (炮管后缩 0.1s)
- **每座塔可独立升级** (Lv.1→3), 升级时外观进化 (L1→L2→L3); 同一条围墙上的塔等级可以不同, 战场上"一眼看出哪座塔升过"

**环境装饰** (提升场景丰富度, 低成本):
- 城外: 枯树、弹坑、废弃军车、铁丝网、路障 (2-3 处)
- 城内: 弹药库、油桶、沙袋工事、旗帜杆
- 远景: 低模山丘 + 雾, 剪影化处理

### 2.6 传送门建模 (怪物出生点, 核心氛围资产)

> 传送门是"怪物从哪来"的视觉答案, 必须**微微发亮、有神秘感**, 是场景里除基地建筑外最亮的东西。

**形态**:
- 椭圆形能量光门 (高 3m × 宽 2m), 悬浮于地面石质基座之上 (基座: 圆形混凝土台 + 4 根断裂石柱环绕, 带符文/电路雕刻)
- 门体: 内部漩涡状能量 (Shader 实现: 噪声扭曲 + 自发光, 紫绿色调), 边缘有 2 圈旋转符文环 (反向旋转)
- 地面: 基座周围 3m 范围有发光符文圈 (自发光贴图, 随充能变亮)

**3 级状态** (对应波次节奏):
| 状态 | 外观 | 触发 |
|---|---|---|
| 休眠 | 暗紫色微光, 符文环缓慢旋转, 粒子稀疏 | 默认 (波次间隙) |
| 充能预警 | 光门变亮 (亮度 ×2), 符文环加速, 粒子向门内汇聚, 地面符文圈点亮 | 该方向怪物生成前 2s |
| 开启 | 光门全亮 (紫绿色漩涡加速), 边缘电弧粒子, 怪物从中挤出 | 怪物出生期间 |

**3 个传送门路线色** (与 HUD 三路敌情条一致, 帮助玩家识别路线):
- 左门: 红色调 / 中门: 紫色调 / 右门: 绿色调 (仅符文圈与边缘光变色, 门体主色保持紫绿)

**性能**: 传送门 Shader 用 2D 平面 + 自定义 Shader (不用 3D 体积), 3 个门同屏 Draw Call ≤ 6。

### 2.7 特效 (VFX)

| 特效 | 方案 |

## 4. 场景构图 (3D 相机, 竖屏)

```
默认相机: 俯角 55°, 距离基地中心 34m, 正对基地 (全战场俯瞰)
视野: 基地占屏幕下 1/3, 三路行军区占上 2/3, 上下各留 12% 给 HUD
场景尺寸: 传送门在顶部 (距大门约 24m, 30s 行军距离), 基地在底部, 场景总纵深 ≈ 30m, 宽 ≈ 24m
层次:
  远景 (雾中, 场景上部): 山丘剪影 + 枯树 + 3 个传送门
  中景 (场景中部): 3 条斜线路线 + 行军怪物
  近景 (场景底部): 基地围墙 + 大门 + 防线友军 + 主城/兵营/实验室 (玩家视线焦点)
```

**相机行为** (详见《01-游戏设计文档》3.2 节):
- 默认锁定基地中心, 玩家可上下拖拽/小角度旋转/缩放
- 双击某传送门/大门 → 相机 0.5s 平滑推近 (距离 8m, 俯角 45°)
- 点击主城/兵营/实验室 → 进入对应页面
- "⌂ 回中"按钮 → 回到默认位
- 传送门充能预警时: 若该门在视野外, HUD 对应路线箭头闪烁 (引导玩家拖过去看)
- 大门 HP<50% 且不在视野内: 相机轻微自动平移 (不抢控制权)
- 屏幕震动: Boss 出场 / 门破碎 / 门破倒计时开始 / 高达登场 (幅度 ≤ 0.3m, 时长 ≤ 0.5s)

**LOD 策略** (配合自由相机):
- 怪物: 距离 > 20m 关骨骼动画 (用 2 帧贴片), > 28m 隐藏 (雾中)
- 友军: 距离 > 20m 关骨骼动画 (用贴片)
- 高达: 始终全精度 (数量少, 最多 3 台)
- 空军: 始终全精度 (数量少, 最多 3 架)
- 传送门: 始终全精度 (数量少, 仅 4 个)
- 环境装饰: 距离 > 25m 用剪影贴片
