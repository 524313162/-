# 《丧尸围城》成长树设计

> 版本: v0.4 (配合三路汇聚布局)
> 科技点 (TP) 获取: 每波结算 +1, 精英波 +2, Boss 波 +3
> 规则: 每局重置; 节点需前置节点已解锁; 每节点消耗 1-3 TP
> 注意: 科技树是"局内数值强化"; "解锁新兵种/塔/高达/空军"在**兵营**用金币完成 (跨局保留); "升级主城/大门/修理工"在**主城**, "全局攻防/塔强化"在**实验室**

---

## 1. 总览图

```
                    ┌─────────────┐
                    │   兵种分支   │  量产兵种强化
                    │ (火枪/机枪) │
                    └──────┬──────┘
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
┌───────┴───────┐  ┌───────┴───────┐  ┌───────┴───────┐
│   火力分支    │  │   城防分支    │  │   后勤分支    │
│(塔/高达/空军)│  │(门/修理工/城)│  │ (主城产能/经济)│
└───────────────┘  └───────────────┘  └───────────────┘
```

4 分支 × 5 级 = 20 节点, 单局最多可点 12-15 个 (TP 获取速度限制), 迫使玩家每局做取舍。

## 2. 兵种分支 (量产兵种强化)

> 主题: 让主城量产的兵种更强

| 级 | 节点名 | 消耗 | 效果 | 设计意图 |
|---|---|---|---|---|
| M1 | 强化弹药 | 1 TP | 火枪手/机枪手伤害 +20% | 入门, 强化基础量产 |
| M2 | 穿甲弹头 | 1 TP | 狙击手/火箭筒对装甲伤害 +30% | 入门, 反装甲 |
| M3 | 鹰眼训练 | 2 TP | 所有兵种射程 +15% | 质变: 射程是塔防核心 |
| M4 | 连发机构 | 2 TP | 所有兵种攻速 +15% | 与 M3 形成"伤害流 vs 攻速流" |
| M5 | 精锐军团 | 3 TP | 满级兵种额外 +50% 伤害 | 终局, 鼓励把兵种升满 |

**分支策略**: 前期 M1/M2 必点 (便宜); M3 vs M4 是核心抉择 (射程流打快速丧尸, 攻速流打肉盾)。

## 3. 火力分支 (塔/高达/空军)

> 主题: 让围墙塔、高达与空军成为主力输出

| 级 | 节点名 | 消耗 | 效果 | 设计意图 |
|---|---|---|---|---|
| E1 | 塔身加固 | 1 TP | 所有塔伤害 +25% | 入门 |
| E2 | 高爆火箭 | 1 TP | 火箭炮塔溅射半径 +40% | 入门, 强化范围 |
| E3 | 白刃强化 | 2 TP | 白色高达双枪伤害 +40%, 移速 +20% | 质变: 白色高达流核心 |
| E4 | 猎鹰机炮 | 2 TP | 战斗机扫射伤害 +40%, 整备时间 -1s | 质变: 战斗机流核心 |
| E5 | 秃鹫重弹 | 3 TP | 投弹机每趟 +2 枚, 溅射 +30%; 所有高达伤害 +30% | 终局, 空军/高达流核心 |

**分支策略**: 与兵种分支互斥感强——TP 有限, 玩家倾向"量产流"、"高达流"或"空军流"之一, 形成 build 多样性。

### 3.1 实验室金币升级线 (v0.4 新增, 非 TP)

> 实验室除科技树 (TP) 外, 还有一条**金币消耗**的全局强化线, 即原"铁匠铺"定位: 主要升级 **攻击 / 速度 / 防御** 与 **防御塔的攻击和防御**。与"每座塔单独升级"叠加生效。

| 线 | 每级效果 | 最大级 | 消耗 | 说明 |
|---|---|---|---|---|
| ⚔ 攻击 | 全体友军 + 主城炮位伤害 +8% | 10 | 金币递增 | 全局输出 |
| ⏩ 速度 | 全体友军攻速 +5%, 移速 +3% | 10 | 金币递增 | 全局节奏 |
| 🛡 防御 | 大门/主城 HP +6%, 受伤 -4% | 10 | 金币递增 | 全局生存 |
| 🗼 塔强化 | **所有防御塔** 攻击 +10% / 护甲 +10% | 8 | 金币递增 | 全局塔加成, 与单塔独立升级叠加 |

## 4. 城防分支 (大门/修理工/主城)

> 主题: 让大门与主城更耐打, 让修理工修得更快——本作核心保命分支

| 级 | 节点名 | 消耗 | 效果 | 设计意图 |
|---|---|---|---|---|
| F1 | 加固门板 | 1 TP | 大门 HP +30% | 入门, 最稳投资 |
| F2 | 电磁门闩 | 1 TP | 大门被啃咬时, 怪物攻速 -15% | 入门, 拖慢破门节奏 |
| F3 | 熟练修理工 | 2 TP | 修理工修复速度 +50% | 质变: 修理工流核心 |
| F4 | 主城装甲 | 2 TP | 主城 HP +40%, 炮位伤害 +20% | 质变: 主城流核心 (血量更厚 + 火力更强) |
| F5 | 自动重建 | 3 TP | 大门坍塌后 20s 自动以 50% HP 重建 (每局限 2 次) | 终局, 硬核玩家保底 |

**分支策略**: F1/F3 是修理工流必点; F4 强化主城 (血量 + 火力), 适合"主城流"; F5 让大门坍塌后能自动重建, 后期容错极高, 但 3 TP 代价大, 与兵种/火力分支强互斥。

## 5. 后勤分支 (主城产能/经济)

> 主题: 让主城增兵更快、上限更高, 让金币滚雪球

| 级 | 节点名 | 消耗 | 效果 | 设计意图 |
|---|---|---|---|---|
| G1 | 战利品搜刮 | 1 TP | 击杀金币 +20% | 入门, 最稳投资 |
| G2 | 兵工厂扩建 | 1 TP | 主城产能 +1 (1→2) | 与 G1 二选一 (加钱 vs 加兵) |
| G3 | 扩编命令 | 2 TP | 友军上限 20 → 25 | 中期, 更多有生力量 |
| G4 | 快速动员 | 2 TP | 主城增兵间隔 10s → 7s | 质变: 增兵更快 |
| G5 | 战争机器 | 3 TP | 友军上限 → 30, 产能 +1 | 终局, 量产流核心 |

**分支策略**: 后勤分支是"加速器", 不直接加战力, 但让量产防线成型更快; 适合追求高波数的玩家。

## 6. 跨局成长 (Meta Progression, 兵营金币解锁)

> 与局内科技树独立, 跨局永久保留, 提供长线目标。用**金币**解锁 (非 TP)。

| 解锁项 | 条件 (累计存活波数) | 说明 |
|---|---|---|
| 火油投手 | 4 波 | 解锁新兵种 (灼烧) |
| 狙击手 | 6 波 | 解锁新兵种 (反 Boss) |
| 喷火兵 | 8 波 | 解锁新兵种 (近距反群) |
| 机枪手 | 10 波 | 解锁新兵种 (快攻反群) |
| 火箭筒 | 13 波 | 解锁新兵种 (重击反装甲) |
| 轨道炮手 | 16 波 | 解锁新兵种 (穿透反 Boss) |
| 火箭炮塔 | 12 波 | 解锁新塔 |
| 战斗机「猎鹰」 | 14 波 | 解锁空军 (空中扫射, 2 回合返回) |
| 白色高达「白刃」 | 15 波 | 解锁王牌机甲 (地面双枪) |
| 投弹机「秃鹫」 | 18 波 | 解锁空军 (空中投弹, 范围攻击) |
| 红色高达「赤焰」 | 22 波 | 解锁王牌机甲 (飞行导弹) |
| 电磁塔 | 20 波 | 解锁新塔 (v1.1) |
| 飞行丧尸怪物 | 15 波 | 新怪物 (增加难度) |
| 皮肤: 雪原基地 | 25 波 | 纯外观 |
| 皮肤: 熔岩基地 | 40 波 | 纯外观 |

**设计原则**:
- 跨局解锁只给"新内容" (兵种/塔/高达/空军/怪物/皮肤), 不给数值 → 保持局内公平
- 解锁进度在开始界面展示, 给玩家"再来一局"的动力
- 高达解锁门槛高 (15/22 波), 空军门槛中 (14/18 波), 是长线追求目标

## 7. 科技树 UI 交互

```
┌─────────────────────────────┐
│  科技树          [关闭 ✕]   │
│  剩余科技点: ◆ 3            │
│                             │
│  [兵种] [火力] [城防] [后勤] │  ← 分支 Tab
│                             │
│      ●─────────○─────────○  │
│     M1(已点)   M2(可点)  M3(锁)│
│                             │
│  ┌─────────────────────┐    │
│  │ 鹰眼训练 (M3)        │    │
│  │ 所有兵种射程 +15%    │    │
│  │ 消耗: ◆ 2           │    │
│  │ [ 解锁 ]            │    │
│  └─────────────────────┘    │
└─────────────────────────────┘
```

- 节点状态: 已解锁 (金色发光) / 可解锁 (白色) / 锁定 (灰色 + 锁图标)
- 点击节点 → 底部详情卡 → 确认解锁
- 解锁时: 节点连线点亮动画 + 音效 + 全屏轻微闪光
- 科技树入口: **实验室**页面内的"科技树"Tab (仅波次间隙可打开, 战斗中禁用)

## 8. 数值校验 (单局 TP 预算)

| 波次 | 累计 TP | 可点节点数 (平均 1.5TP/节点) |
|---|---|---|
| 5 | 5 | 3 |
| 10 | 11 (含 Boss +3) | 7 |
| 15 | 17 | 11 |
| 20 | 24 (含 2 Boss) | 16 |
| 30 | 39 | 26 (全树 20 节点, 已点满) |

**结论**: 约 25 波左右可点满全树, 与"第 20 波普通玩家天花板"的定位吻合; 30 波+ 玩家靠跨局解锁 (高达/新兵种) + 满级 build 支撑。
